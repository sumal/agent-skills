# Kerala CM — Rapid Decision Skill

## Core Mandate & Top 3 KPIs
1. **Internal security & rule of law** — communal harmony, naxal/terror containment, women & child safety (Pink Police, women-only stations), zero custodial deaths.
2. **Administrative reform & e-governance velocity** — file disposal time at Secretariat, K-SMART rollout, e-Office adoption, citizen service SLA on e-District.
3. **NRI welfare + investment leverage** — NORKA-Roots services for ~25 lakh Malayalee diaspora, remittance economy (~₹2.3 lakh cr/yr), repatriation in crises, diaspora-funded projects.

## Rapid Decision Matrix (4-step)
1. **Legality / Constitutionality** — Article 256/257 directions vs State autonomy; Police Act 1960; All India Service Rules; Vigilance Manual; OBR/Cabinet Note format compliant?
2. **Exchequer & Federal Cost** — Implication on State budget, CSS leverage (MHA, MEITY, MEA), 15th FC grants, possible PFMS hold-up.
3. **Sustainability / Communal Stability** — Will the call worsen monsoon-period disorder, coastal/border vulnerability, religious flashpoints, social media fault lines?
4. **LSGI / Welfare Alignment** — District-level reception, SC/ST/Minority/migrant-worker impact, Kudumbashree/Janamaithri Police interface.

## Stakeholder Consultation Map
- **Tier 0:** Chief Secretary, DGP, ACS Home, ACS Finance, ACS GAD, AG Kerala, Resident Commissioner Delhi
- **Tier 1:** Cabinet Sub-Committees, Speaker (for Assembly business), all Ministers (cabinet collegiate)
- **Tier 2:** State Police Chief, IB/SIB, NIA liaison, Coastal Police, NORKA, KSITM, K-DISC
- **Tier 3 (Centre):** MHA, PMO, Cabinet Secretariat, MEA (NRI), MEITY (digital), DoPT (IAS)
- **Tier 4:** District Collectors/SPs, religious heads (Hindu/Muslim/Christian apex bodies), media editors (vernacular + national), Pravasi associations (Gulf, US, EU, AU)

## Top 3 Risks & Crisis SOP

### R1. Communal Flare-up / Public Order Breakdown
24h: SP brief → Sec.144 / preventive arrests → Peace Committee → state-wide alert; 72h: Cabinet Sub-Committee on Internal Security; comms via DGP + IPRD only, vernacular first; consider judicial inquiry to defuse.

### R2. IAS/IPS Cadre Crisis (transfer dispute, central deputation pull-back, court stay)
24h: CS + Chief Secy DoPT call → file Cabinet note for tenure-protection citation; 72h: counter-affidavit via AG; engage Centre via Resident Commissioner.

### R3. NRI Repatriation / Diaspora Crisis (Gulf war, deportation, ship/air evacuation)
24h: Activate NORKA Control Room + MEA Operations Centre; 72h: charter coordination, CMDRF appeal, state airport-side reception via District Collectors and Kudumbashree.

## Kerala-Specific Innovations
1. **K-SMART unified citizen platform** — extend single-sign-on to all 1,200+ LSGI services; track minister-level dashboards on file pendency.
2. **Janamaithri Suraksha 2.0** — community-policing data layer fused with KSDMA early-warning for monsoon law-and-order pre-positioning.
3. **NORKA Diaspora Bond + Skill Registry** — instrument-grade Pravasi bonds (RBI window) + verified skill registry to short-circuit Gulf job placements via NORKA-Roots.
