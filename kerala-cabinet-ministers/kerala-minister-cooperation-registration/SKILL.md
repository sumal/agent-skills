# Kerala Co-operation & Registration Minister — Rapid Decision Skill

## Core Mandate & Top 3 KPIs
1. **Healthy co-operatives** — NPA in co-op banks under threshold, PACS computerisation (national mission), audit current-year coverage, dormant societies wound up.
2. **Co-op-led financial inclusion** — Member deposits, agri-credit flow via PACS+DCBs+KSCB, MSME credit via urban co-op banks.
3. **Registration revenue + service** — Stamp + registration revenue (~₹4,500 cr/yr), e-Registration (Pearl/ENTHU) uptime, fair-value/circle-rate accuracy.

## Rapid Decision Matrix (4-step)
1. **Legality** — Kerala Co-op Societies Act 1969 + Rules, Banking Regulation Act (Co-op) 1949 + 2020 amendment (RBI co-jurisdiction), Indian Stamp Act 1899 + Kerala Stamp Act 1959, Registration Act 1908, IT Act 2000 (digital signing), KAAPA (vigilance overlap).
2. **Exchequer** — Stamp + registration revenue, audit fee, co-op DCC/RCS budget, rehab packages for stressed co-ops.
3. **Sustainability** — Climate-resilience credit windows, green-financing via DCBs/PACS, paperless registration carbon impact.
4. **LSGI / Welfare** — PACS at panchayat level, women in co-op leadership (Kudumbashree-linked), SC/ST co-op support (Anweshi-style schemes), tribal-area registration camps.

## Top 3 Risks & Crisis SOP

### R1. Co-op Bank Run / NPA Spike / RBI Section-35 Action
24h: RCS + KSCB + RBI Regional liaison; freeze withdrawals only if absolutely necessary; 72h: rehab plan via NABARD + Govt support letter, depositor reassurance via IPRD, Cabinet note on guarantee if systemic.

### R2. Registration Portal Outage / Stamp-duty Court Order
24h: NIC/CDAC + IGR + Law Secy; manual fallback for marriage/births; 72h: counter-affidavit, software hot-fix, refund SOP for over-charging, Cabinet update on revenue.

### R3. Co-op Election / Vigilance Scandal
24h: RCS + Vigilance Director; 72h: special audit, suspensions, AG opinion on supersession, communication via IPRD.

## Kerala-Specific Innovations
1. **PACS-as-Service Hub** — every PACS upgraded into rural services hub (CSC + DigiLocker + JJM tariff + LSGI helpdesk + insurance + KASP enrolment + e-Mandi front-end), funded by Centre's PACS computerisation + State + LSGI.
2. **Pearl + e-Registration 2.0 (Document-stack + Aadhaar + Blockchain)** — paperless registration with e-stamp, Aadhaar e-sign, GIS plot-overlay, anchored on permissioned ledger; cuts registration time from days to <30 minutes.
3. **Women-Led Co-ops Scaling** — convert 5,000 Kudumbashree CDS into formal multi-purpose co-ops with KSCB credit-line and Milma/Matsyafed/Supplyco market access.
