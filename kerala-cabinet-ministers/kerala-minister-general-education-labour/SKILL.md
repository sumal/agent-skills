# Kerala General Education & Labour Minister — Rapid Decision Skill

## Core Mandate & Top 3 KPIs
1. **Public school excellence** — Learning outcomes (NAS/SLAS/PARAKH), public-school enrollment retention, hi-tech classroom uptime, equitable SC/ST/coastal/tribal outcomes.
2. **Skill-employment match** — KASE/ASAP throughput, apprenticeship placement, Kerala Knowledge Economy Mission roles filled.
3. **Labour rights + dignified migration** — Welfare board enrollment, "Aawaz" health card for ~30 lakh inter-state migrant workers, ID Act dispute resolution time.

## Rapid Decision Matrix (4-step)
1. **Legality** — RTE Act 2009, Kerala Education Act 1958 + Rules 1959, NEP 2020 alignment, ID Act 1947, Code on Wages 2019, OSH Code 2020, Inter-State Migrant Workmen Act 1979, BoCW Act 1996, Apprentices Act 1961.
2. **Exchequer** — PM-POSHAN CSS share, KITE recurring, hi-tech equipment renewal, welfare board corpus, KASE/KKEM CSS leverage.
3. **Sustainability** — Green-school audits, climate-resilient school buildings (cyclone/flood), heat-action plan for outdoor labour, EV-mobility transition for delivery workers.
4. **LSGI / Welfare** — LSGI ownership of school infra under KPR/KM Act, women teachers majority, SC/ST scholarship + transport, migrant-worker hostels via Kudumbashree.

## Stakeholder Consultation Map
- **Tier 0:** Chief Secretary, ACS Education, ACS Labour, DPI, Director SCERT, KITE CEO, Labour Commissioner
- **Tier 1:** District Panchayats/ULBs (school maintenance), KILA
- **Tier 2:** SSK, NCERT (CSS), Kerala State Higher Sec. Examination Board, KCBSE coordination, KASE, KKEM, Welfare Boards (BoCW, motor transport, head-load, etc.)
- **Tier 3 (Centre):** MoE (DoSEL), Ministry of L&E, NCERT, NCTE, ESIC, EPFO
- **Tier 4:** KSTA + recognized teacher unions (KSTU, KPSTA, GTU), parent-teacher associations, recognized labour unions (CITU/INTUC/AITUC/BMS), Aawaz card outreach NGOs

## Top 3 Risks & Crisis SOP

### R1. Mid-Day Meal / PM-POSHAN Food-Safety Incident
24h: FSSAI + DH brief, supply chain freeze, hospital coordination, ex-gratia; 72h: recipe/vendor audit, SOP revision, parent communication via PTA, FIR if culpability.

### R2. Teacher Strike / Recruitment Dispute (PSC vs aided sector)
24h: Labour Commissioner conciliation + Education Secy joint meeting; 72h: settlement memo, no ESMA on schools (avoid politicization), Cabinet note if revenue implication.

### R3. Migrant-Worker Mass Incident (heat death, accident, communal flare-up)
24h: Labour Commissioner + Police + Aawaz Centre activation; 72h: ex-gratia via BoCW board, source-state liaison, employer action, MEA-style protocol via Aawaz cell.

## Kerala-Specific Innovations
1. **AI-Tutor in Public Schools (KITE-led)** — vernacular-first AI literacy tutor for grades 6–10, deployed on existing hi-tech classroom hardware, with teacher-in-the-loop.
2. **Aawaz 2.0 — Migrant Worker Stack** — biometric Aawaz health card + portable BoCW benefit + GIS-mapped labour camps + Malayalam helpline; integrate with e-Shram (Centre).
3. **KKEM × Kudumbashree Skill Bridge** — convert Kudumbashree micro-enterprises into KKEM-recognised skill clusters (caregiving, EV repair, hospitality) with assured placements via diaspora demand.
