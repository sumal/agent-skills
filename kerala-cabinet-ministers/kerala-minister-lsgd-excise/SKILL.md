# Kerala LSGD & Excise Minister — Rapid Decision Skill

## Core Mandate & Top 3 KPIs
1. **Strong devolution + LSGI capacity** — % Plan Fund + 15th FC grants utilised by LSGIs, LSGI annual plan approval timeline, K-SMART adoption across 1,200+ LSGIs.
2. **Sanitation & solid-waste leadership** — Source-segregated waste in all ULBs, scientific MCF/RRF coverage, Suchitwa Mission targets, plastic-free panchayats.
3. **Excise revenue + harm reduction** — ₹3,000+ cr/yr revenue, BEVCO operational discipline, de-addiction (Vimukthi), narcotics-free campus drive.

## Rapid Decision Matrix (4-step)
1. **Legality** — Kerala Panchayat Raj Act 1994, Kerala Municipality Act 1994, Kerala Building Rules 2019, MGNREGA, Solid Waste Mgmt Rules 2016, Plastic Waste Mgmt Rules, Abkari Act 1077 ME, NDPS Act 1985.
2. **Exchequer** — Plan fund (≥25–30% State Plan), 15th FC tied/untied grants, MGNREGS state share, BEVCO P&L, Excise duty leakage.
3. **Sustainability** — Decentralised waste mgmt > centralised burn, wetland/paddy protection in LSGI building permits, Climate-Smart Local Plan template.
4. **LSGI / Welfare** — Mandatory gram/ward sabha process, SC/ST/Tribal sub-plan, Kudumbashree integration, women & PwD reservation respect.

## Top 3 Risks & Crisis SOP

### R1. Waste Crisis / Garbage Mountain Fire (e.g., Brahmapuram-style)
24h: NGT-compliant fire suppression + air-quality monitoring + medical camps; 72h: scientific capping plan, bio-mining tender, LSGI-level segregation enforcement; daily presser; HC compliance affidavit.

### R2. LSGI Plan-Fund Lapse / Audit Failure
24h: Director + KILA review; 72h: extension via Cabinet note (within FY rules), social audit, GP-wise re-prioritisation, K-SMART data lock.

### R3. Liquor Policy / Prohibition Court Order
24h: AG + Excise Commissioner briefing; 72h: counter-affidavit, revenue impact note for Cabinet, communication strategy via IPRD.

## Kerala-Specific Innovations
1. **K-SMART unified LSGI platform** — single citizen + employee + plan-monitoring stack across all 1,200+ LSGIs; Minister dashboard on file pendency, plan utilisation, building permits.
2. **Haritha Karma Sena 2.0** — formalise 35,000+ Kudumbashree women into a state-recognized waste-collection cadre with PF/ESI, EV three-wheelers (ANERT-funded), digital user-fee app.
3. **Janakeeyasoothranam 2.0 — Climate-Smart Local Plan** — embed climate-vulnerability layer (KSDMA) + carbon-budget into LSGI annual plan template; tied to 15th FC performance grant.
